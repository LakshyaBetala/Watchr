# Welcome to Watchr — VisionIQ Dashboard

## Project info

Built with: Vite, TypeScript, React, shadcn-ui, Tailwind CSS, Framer Motion, Recharts.

## How to run locally

```sh
# Install dependencies
npm install

# Start the dev server (http://localhost:8080)
npm run dev
```

## Tech Stack

- **Framework**: React 18 + Vite 7
- **Styling**: Tailwind CSS + shadcn/ui
- **Animation**: Framer Motion
- **Charts**: Recharts
- **Icons**: Lucide React
- **Routing**: React Router v6
